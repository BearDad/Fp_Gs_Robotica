\fchapter[Integración, funciones y...]{Integración, funciones y objetivos del sistema de control. (Descripción)}

Interfaz hombre-máquina: En este apartado debemos describir cómo interactúa la máquina con
el operario y que funciones realiza al pulsar determinados pulsadores o mostrar algunos pilotos.

Cómo se dan las órdenes por parte del operario: pulsadores (marcha, paro, emergencia, etc…),
conmutadores, mediante HMI, ESCADA, sistemas de manejo por voz, etc.

Cómo recibe información el operario por parte del sistema: Indicadores acústicos, pilotos y Balizas
de señalización. Sistemas interactivos como: pantallas Gráficas de Operario, ordenadores con
software de control tipo SCADA, pantallas de mensajes de texto con teclados, impresoras, etc.
De cada uno de ellos realizaremos una descripción indicando:

\begin{itemize}
	\item Tipo/nombre.
	\item Función o funciones en el sistema, integrando todas las características de control.
	\item Código para referencias y/o etiquetas.
	\item Características (potencia, colores, dimensiones).
	\item Programas de configuración, datos, etc.
	\item Instalación y los terminales para su conexión.
	\item Sistema de comunicación (si lo hay).
	\item Ubicación.
\end{itemize}
